Contract Monthly Claim System (CMCS)

Summary
 Using ASP.NET Core MVC, a prototype web application called the Contract Monthly Claim System (CMCS) was created.  
 It is intended to make it easier for Independent Contractor (IC) lecturers to submit, monitor, and approve monthly claims.

 This repository includes Part 1 – Planning and Prototype Development, which uses mock interfaces and static data to illustrate the system workflow.


Features (Prototype) - Lecturer Dashboard 
- Login & Register Pages
- Claim submission and tracking
- View claims
- Coordinator Dashboard.
- Pre-Approve Page  Accept
- Manager Dashboard
- Approve Page
